# Независимое сравнение маршрутов

## Решение от 2026-09-16

Наш алгоритм и Gemini должны самостоятельно строить маршруты. Общие входные данные — только направление и условия поездки. Передавать граф, промежуточные узлы или выдачу одного участника другому нельзя. Проверка предложений выполняется после поиска; отсутствие связи в нашем графе не доказывает ошибку чужого предложения.

Прежний эксперимент на вручную выбранных связях Rome2Rio не удовлетворял этому требованию. Его результаты GraphPlanner и Gemini сняты с экрана и заменены отчётом версии 2. Совпадения того эксперимента не подтверждают качество независимого поиска. Старая топология сохранена только как отдельный тестовый пример в Gemini, не как источник отчёта.

## Реализовано и что осталось

- **Gemini:** отдельный метод Search получает только origin, destination, max_candidates. Системный запрос находится в `services/search/internal/gemini/discovery.go` и целиком включён в отчёт. Модель самостоятельно предлагает промежуточные пункты и транспорт; ответ не проверяется по графу конкурента. Веб-поиск не подключён: это непроверенные гипотезы по знаниям модели, а не подтверждённые актуальные перевозки. Проверяются формат и размеры ответа; ограничения и сомнения модели показываются отдельно.
- **GraphPlanner:** независимый источник реальных транспортных связей ещё не подключён. В отчёте статус unavailable, без подстановки чужих данных или тестовых маршрутов. Следующий предложенный шаг — проверить Яндекс Расписания как источник отдельных поездов и авиарейсов, сохранив построение маршрута в нашем алгоритме.
- **Rome2Rio исключён** по решению пользователя. Его выдача и ссылки удалены из отчётов версии 3 и экрана. Замену третьего источника пока не выбирали.

Остаются два участника; собственный источник нашего алгоритма ещё не подключён. Успешный ответ Gemini не означает подтверждение его маршрутов.

## Воспроизведение

```sh
SEARCH_GEMINI_MAX_OUTPUT_TOKENS=4096 make search-compare-real > /tmp/travel-watch-independent-report.json
```

Четыре направления: Рязань → Пхукет, Москва → Бангкок, Владивосток → Пхукет, Курск → Паттайя. Без конкретных дат, цен и гарантий стыковок. Ключ читается из игнорируемого `.env`, параметры — из YAML/env. Запросы последовательные, ограничены таймаутом, без автоматических повторов. В зафиксированном независимом прогоне получено по четыре предложения Gemini; совпадения с другими участниками не навязывались.

Код возврата 0 означает формирование отчёта, а не успех каждого поиска. Ошибка сохраняется отдельным статусом; отсутствие ключа отличается от пустой выдачи. После проверки JSON обновляется `frontend/src/reports/route-comparison.json`. В нём нет данных пользователей или секретов.

## Кабинет и проверки

В карточке заявки выбирается отдельный экспериментальный отчёт; он не рассчитывается по датам и пассажирам этой заявки. В секции Gemini можно раскрыть точный системный запрос. Предупреждения отображаются красным; стыковки по времени не проверены. Известная невозможная стыковка не должна становиться разрешённой из-за мягкой рекомендации.

Тесты проверяют отсутствие чужих данных в запросе Gemini, независимость от изменения Rome2Rio, сохранение новых предложенных узлов, ошибки и недоступный источник GraphPlanner. В CI внешний API не вызывается. Старый `make search-compare` остаётся отдельным тестом двух алгоритмов на одинаковом синтетическом графе и не является независимым поиском.
