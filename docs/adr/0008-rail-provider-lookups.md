# 0008. Поиск железнодорожных станций через провайдеров Collector

- Статус: принято, 2026-09-16.

## Контекст

Единого выбранного источника пассажирских станций мира нет. Справочники различаются по покрытию, идентификаторам и условиям использования. Нужно подключать страны и поставщиков постепенно, без обязательного полного импорта станций.

## Решение

- Collector владеет адаптерами внешних железнодорожных провайдеров. Отдельный микросервис только для станций не создаём.
- Поиск станций и поиск поездов — независимые интерфейсы; провайдер может реализовать один или оба.
- Идентификатор источника и код объекта хранятся вместе. Коды ЕСР/Экспресс-3 необязательны; одинаковые названия не служат основанием объединения станций.
- Станции ищутся онлайн по необходимости. Найденные узлы планируется сохранять в Search для устойчивых ссылок; механизм обмена и кэширования выбирается при подключении реального источника с учётом его условий.
- Search отвечает за выбор участков и сборку маршрутов, Collector — за получение и нормализацию данных поставщика.
- Полнота ответа ограничена провайдером и запросом. Ошибки, неподдерживаемое покрытие и пустой результат различаются. При ошибке результат не используется.

## Последствия

Реализованы только внутренние Go-интерфейсы и синтетический провайдер. Нет внешних запросов, мирового импорта станций, нового процесса, БД Collector или подключённых брокеров. Для следующего этапа нужны реальный источник, проверка его покрытия/условий, ограничение сетевых операций и отдельные контракты обмена между сервисами. Каталог аэропортов OurAirports остаётся без изменений.

Описание контрактов: [Collector](../services/collector.md).
