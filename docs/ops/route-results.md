# Просмотр схем заявки

Схемы читаются из БД Search через gRPC с mTLS; просмотр не запускает планировщики. [Решение и ограничения](../adr/0012-saved-routes-grpc.md).

## Локально

После [подготовки БД и обработчиков](route-building-progress.md) выполните:

```sh
make tls-init
make search-results
```

В другом терминале запустите или перезапустите `make cabinet`. Команды загружают свои `.local/tls/search.env` и `.local/tls/cabinet.env`; уже установленные переменные окружения имеют приоритет. Search слушает `127.0.0.1:9093`, Cabinet подключается к `https://localhost:9093`, проверяя сертификат с именем `search`. Без включённого клиента Cabinet показывает явную недоступность схем, остальные операции с заявкой работают.

В карточке выберите секцию «Схемы» в нижней стрелке. Каждый источник имеет собственные варианты, счётчик и страницы. Результат завершившегося источника доступен, пока другой работает. Возврат на предыдущий этап не запускает построение повторно. Ошибка Search сохраняет уже показанные схемы и черновик комментария; доступна кнопка повтора.

## Compose

`make stage-local-up` и `make dev-up` вызывают `tls-init` и запускают отдельный процесс `search-results`. У него нет опубликованного порта: Cabinet обращается по внутренней сети. Каждый контейнер получает только свой TLS env-файл. Dev требует образов с этой реализацией; запуск старого опубликованного образа не проверяет локальные изменения.

## Сертификаты

Генератор предназначен только для локальных окружений. Каталог имеет права 0700, файлы 0600; `.local` исключён из Git и Docker context. CA действует 3 месяца, сертификаты сервисов — месяц. Приватный ключ CA остаётся в памяти генератора, на диск не записывается. Существующие файлы не перезаписываются, неполный комплект приводит к ошибке.

При истечении срока остановите использующие комплект процессы, переместите оба env-файла в защищённый архив, выполните `make tls-init` и перезапустите оба сервиса. Это заменяет весь локальный комплект; не смешивайте старый и новый CA. Для сервера нужен отдельный управляемый выпуск и ротация, локальный генератор не заменяет менеджер секретов.

Настройки — `results` в YAML Search и `search` в YAML Cabinet; env-префиксы `SEARCH_RESULTS_*` и `CABINET_SEARCH_*`. TLS-поля: `CA_BASE64`, `CERT_BASE64`, `KEY_BASE64`, `PEER_NAME`. Не печатайте конфигурацию с секретами и не добавляйте реальные значения в документацию.

## Проверки

TLS-тест проверяет реальный HTTP2 gRPC и отклонение клиента без сертификата, с чужим CA или другим именем. RPC-тест Cabinet проверяет владение до обращения в Search. Интеграционные тесты БД проверяют независимые страницы источников; браузерный сценарий — переключение этапов, отсутствие повторных запросов без изменений, пагинацию, ошибку и восстановление.

## Пересылка схем

Кнопки «Скопировать показанные маршруты» и «Скачать показанные маршруты TXT» выгружают текущие страницы всех показанных источников. Остальные страницы автоматически не загружаются. В раскрытом варианте можно скопировать только его. Текст включает нумерацию, источник, время получения, участки и предупреждения о неполноте и непроверенных стыковках. При запрете доступа к буферу интерфейс предлагает скачать TXT. Выгрузка не запускает новый поиск.
