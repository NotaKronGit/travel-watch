# Онлайн-поиск железнодорожных станций

Collector реализует `StationProvider` для Яндекс Расписаний. Это ручная диагностика источника: результаты выводятся в JSON, не записываются в БД, не кешируются и не участвуют в построении маршрутов автоматически. Расписания, цены и наличие мест пока не запрашиваются.

## Запуск

Из корня проекта добавьте ключ в игнорируемый `.env`:

```dotenv
COLLECTOR_YANDEX_API_KEY=your-api-key
```

Ключ передаётся в HTTP-заголовке `Authorization`, не в URL. Команда не выводит конфигурацию, ключ, тела ошибок или исходные ошибки транспорта. Не добавляйте `.env` в Git.

Пример точки около центра Иваново (WGS84), радиус 20 км:

```sh
make collector-stations-find LAT=56.9972 LON=40.9714
```

Параметры: `RADIUS` — километры, по умолчанию 20, допустимо больше 0 и не больше 50; `LIMIT` — по умолчанию 20. Общий интерфейс допускает до 100 записей, адаптер ограничивает запрос 50 станциями согласно документации источника. При достижении 50 записей полнота консервативно считается неизвестной даже при совпадении с `pagination.total`.

Конфигурация: `services/collector/config.yaml`, другой путь — `COLLECTOR_CONFIG`. Переопределения:

- `COLLECTOR_YANDEX_API_KEY` — обязательный ключ.
- `COLLECTOR_YANDEX_TIMEOUT` — общий HTTP-таймаут, по умолчанию 15s, максимум 1m.
- `COLLECTOR_YANDEX_MAX_RESPONSE_BYTES` — максимум ответа, по умолчанию 1048576, максимум 4194304 байта.

## Семантика и ограничения

Используется `nearest_stations` с `transport_types=train`, русским языком и координатами/радиусом. Один запуск делает один запрос, без автоматических повторов и переходов по редиректам. Поддержка электричек отдельно не заявляется. Радиус 50 км — ограничение нашего MVP.

Идентификаторы принадлежат Яндексу. Ответ этого метода не даёт подтверждённых страны, города, timezone, ЕСР и Экспресс-3: эти поля остаются пустыми. Близость к точке не доказывает принадлежность станции городу и не подтверждает возможность нужной поездки.

`Complete` относится только к выдаче провайдера в заданном радиусе. `LimitReached` и `Complete=false` обозначают усечение; мировое покрытие не предполагается. Ошибки HTTP, некорректные или слишком большие ответы не превращаются в пустой успешный результат. HTTP 429 возвращает `ErrRateLimited`; остальные неуспешные статусы — `ErrUnavailable` с числовым HTTP-кодом без тела ответа.

Проверка 2026-09-16: запрос из примера вернул 13 станций, включая «Иваново» (`s2010050`). Это наблюдение конкретного запроса, не постоянная гарантия покрытия.

## Проверки и следующие шаги

`go test -race ./services/collector/...` использует подменённый HTTP-транспорт, без внешнего API и реальных ключей. Проверяет нормализацию, пустые/неполные ответы, ограничения, ошибки, таймаут, отмену и отсутствие ключа в URL/ошибках. `make lint` проверяет также gosec.

Кеш и Redis пока не добавлены. До сохранения ответов проверить условия поставщика, сроки хранения и обновления. Результаты маршрутов планируются в PostgreSQL Search. Обработчики заданий и межсервисные контракты — следующие этапы.
