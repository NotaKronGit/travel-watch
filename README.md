# Travel Watch

Учебный проект на Go для поиска составных поездок и отслеживания цен на авиа- и железнодорожные билеты. Пользователь задаёт маршрут, даты и условия по цене, а приложение проверяет предложения и уведомляет о подходящих вариантах в Telegram.

Пример поездки: Курск → поезд до Москвы → переезд до аэропорта → прямой рейс до Бангкока. Это иллюстрация сценария; фактическая доступность перевозок зависит от данных источников.

## Первый этап

MVP допускает максимум два основных участка: прямой самолёт, поезд + самолёт или самолёт + самолёт, с необходимыми наземными переездами. Планируются веб-кабинет с заявками, периодические и ручные проверки, история цен и уведомления в Telegram. Покупка билетов не входит в MVP.

## Статус

Реализован первый локальный этап: регистрация, вход, выход и личный кабинет на React Admin с backend на Go. PostgreSQL запускается через Docker Compose. Добавлен отдельный [импорт справочника городов GeoNames](docs/ops/city-catalog.md). Добавлены форма создания заявки, подсказки городов, сохранение параметров поездки, список, просмотр и отмена своих заявок с сохранением истории и личной заметкой. Новые заявки передаются в Kafka через [транзакционный outbox](docs/ops/outbox.md). Search принимает создание и отмену заявок из Kafka; фактический поиск пока не запущен. Добавлены [кандидаты маршрута](docs/specs/route-building.md) и [проверка стыковок](docs/specs/scheduled-journeys.md) на тестовых данных. [Запуск и проверка Search](docs/ops/search.md). Реальные API перевозчиков предстоит исследовать.

Запуск и проверки: [локальная разработка](docs/ops/local-development.md) или [весь кабинет в Docker — stage_local](docs/ops/stage-local.md).

Запуск без локальной сборки: [dev из готовых образов GHCR](docs/ops/dev-images.md) (после первой публикации CI).
