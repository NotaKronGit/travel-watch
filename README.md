# Travel Watch

Учебный проект на Go для поиска составных поездок и отслеживания цен на авиа- и железнодорожные билеты. Пользователь задаёт маршрут, даты и условия по цене, а приложение проверяет предложения и уведомляет о подходящих вариантах в Telegram.

Пример поездки: Курск → поезд до Москвы → переезд до аэропорта → прямой рейс до Бангкока. Это иллюстрация сценария; фактическая доступность перевозок зависит от данных источников.

## Первый этап

MVP ограничен одним городом пересадки и сочетанием поезда с прямым рейсом. Планируются веб-кабинет с заявками, периодические и ручные проверки, история цен и уведомления в Telegram. Покупка билетов не входит в MVP.

## Статус

Проект на этапе проектирования. Приложение пока не реализовано; первый сквозной сценарий будет работать на тестовом источнике. Реальные API ещё предстоит исследовать. Инструкции запуска появятся вместе с реализацией.
